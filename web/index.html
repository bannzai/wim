wim — a Vim-grammar editor in Rust & Wasm

キーボードで直接編集できます。i / a / o で Insert、Esc で Normal、 hjkl w b 0 $ gg G で移動、x dd yy p u と : の Ex コマンドが使えます。Insert と Ex コマンドラインでは日本語入力 (IME) が使えます。 .rs と .md のファイルは tree-sitter でシンタックスハイライトされます。.md のファイルには Markdown Preview プラグインがプレビューパネルを開き、編集するたびに描き直します。

シンタックスハイライトの例:

プラグインを読み込んでいます

プラグインのコマンドはまだ実行していません

autocmd を読み込んでいます

autocmd はまだ実行していません

ファイルを開くと :w で書き戻せます。デーモン経由で開くには手元で wim serve --root . を実行し、表示されたアドレスとトークンを入れてください。デーモンへの接続は Chrome / Edge / Firefox で行ってください。これらは 127.0.0.1 を安全な接続元として扱うため https: のページからでも ws://127.0.0.1 に接続できますが、Safari はこれを許可しません。ローカルファイルは File System Access API 対応ブラウザ (Chrome / Edge) でのみ開けます。
