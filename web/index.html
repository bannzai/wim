wim — a Vim-grammar editor in Rust & Wasm

キーボードで直接編集できます。i / a / o で Insert、Esc で Normal、 hjkl w b 0 $ gg G で移動、x dd yy p u と : の Ex コマンドが使えます。Insert と Ex コマンドラインでは日本語入力 (IME) が使えます。

ファイルを開くと :w で書き戻せます。デーモン経由で開くには手元で wim serve --root . を実行し、表示されたアドレスとトークンを入れてください。ローカルファイルは File System Access API 対応ブラウザ (Chrome / Edge) でのみ開けます。
